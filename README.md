# nested-runner

Self-hosted раннеры GitHub Actions, которые сами крутятся внутри GitHub Actions (`ubuntu-latest`). Матрёшка.

Зачем: доказать, что так можно. Кто потащит в прод — тот лох.

## Как это работает

Локальный контроллер раз в 10 секунд смотрит, сколько у репо свободных раннеров. Если меньше нужного — запускает `runner.yml`, который поднимает ещё один эфемерный раннер.

## Что нажать

### 1. Сделать свой репозиторий

Это твоя матрёшка, а не моя — секреты и раннеры будут жить в твоём репо.

```bash
gh repo fork wprhvso/nested-runner --clone --fork-name nested-runner
cd nested-runner
```

Или проще: кнопка **Use this template** → `gh repo clone owner/name`.

### 2. Включить Actions в форке

В форках workflow'ы выключены по умолчанию. Открыть вкладку **Actions** и нажать зелёную кнопку согласия. Один раз.

### 3. Проверить, что just видит репо

```bash
just vars
```

Должен показать твой `owner/name`. Если пусто — нет remote `origin`, дальше ничего не заработает.

### 4. Залогинить gh

```bash
gh auth login
```

Контроллер ходит в API через `gh` и оттуда же берёт токен для секрета репо.

### 5. Создать конфиг

```bash
just run
```

Конфига нет — `run` создаст его, скажет путь и выйдет. Никакого `login` больше не нужно.

### 6. Заполнить конфиг

Открыть путь, который назвал `just run`, и дописать свой slug:

```toml
poll_seconds = 10

[[repos]]
slug = "owner/name"
warm = 2
```

`warm` — сколько свободных раннеров держать наготове.

### 7. Запустить

```bash
just run
```

Тестовый action:

```bash
just test
```

### 8. Остановить

Ctrl+C в терминале с `just run`, потом:

```bash
just stop
```

## Команды

| Команда | Что делает |
|---|---|
| `just vars` | что just подставляет в остальные рецепты |
| `just run` | запустить цикл |
| `just run --once` | один тик и выход |
| `just stop` | отменить все run'ы и снести всех раннеров |
| `just status` | что контроллер видит прямо сейчас |
| `just runners` | список раннеров |
| `just test` | проверочный workflow |
| `just qa` | yaml, workflow, шелл-скрипты |
| `just clean` | снести состояние контроллера |
